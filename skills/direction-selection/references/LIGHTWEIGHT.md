# Lightweight Direction Selection

Use only after the [applicability router](../SKILL.md#applicability-router) selects `lightweight`. The parent authority rules, Continuation invariant, Support threshold, evidence applicability, and Direction Gate scope apply.

For the bounded choice, establish the goal, hard constraints, ordered criteria, governed commitment, and credible known alternatives. Compare those alternatives at equivalent depth under the same decisive criteria. Use [Close comparisons](../SKILL.md#close-comparisons) for near ties. Count future migration, compatibility, schedule, and operating cost, not sunk effort.

Resolve a cheap decision-sensitive unknown through its fitting evidence route. Read [DISCOVERY.md](DISCOVERY.md) when bounded discovery is warranted; retain this comparison as owner. Challenge a load-bearing reason only when it remains meaningfully uncertain and a cheap realistic check could change the result.

A new [full-mode trigger](../SKILL.md#authoritative-full-mode-triggers) transfers the affected work to [FULL.md](FULL.md), preserving still-valid results. Lightweight comparison does not search for or re-justify a candidate space.

**Complete when:** the parent Support threshold supports `PASS` for the governed commitment, with future-horizon reversibility and a concrete reopen condition; an exact blocker requires `NOT PASSED`; justified adaptive handling applies; or a full-mode trigger transfers ownership.

Return the outcome using the parent's [User-facing presentation](../SKILL.md#user-facing-presentation). For an agent/controller handoff, requested full record, or adaptive outcome, read [OUTCOMES.md](OUTCOMES.md). Return control to the caller, or continue already-authorized standalone work.
